자동 포스팅, 사용자 ✅ 즉시 승인·❌ 보류·보류 없는 60초 자동 승인, 기존 발행 재시도와 중복 방지는 유지한다.

## 공개 사이트

- 기존 Contempo XML과 소개 페이지를 output/adsense_improvements/20261020/에 백업했다. 백업에는 계정 토큰이 없고 공개 테마·페이지 내용만 있다.
- autopost/blogger_theme.py의 improve_theme으로 백업을 변환한다. 알 수 없는 테마 구조나 중복 적용이면 중단한다. XML 문법 확인 뒤 Blogger HTML 편집 UI로 저장한다.
- 비게시글(홈·검색·라벨·보관함·안내·404) 및 미리보기는 CSP script-src 허용 목록으로 광고 로더 실행을 차단한다. 본문 있는 게시글의 광고는 유지한다.
- Blogger가 </head> 직전에 자동 주입하는 AdSense 로더는 반려 상태에서 UI 설정을 편집할 수 없어 HTML에 남는다. CSS 숨김이나 로더 삭제로 성공을 판정하지 않는다. CSP 메타가 자동 주입 이전에 전달되며, 광고 호스트가 허용되지 않는지 확인한다. 네이티브 SEO 메타·소유권·ads.txt는 유지한다.
- 저장을 막던 기존 비활성 AdSense1/2 위젯은 백업 후 제거했다. 새 광고 단위를 만들거나 계정 연결을 해제하지 않았다. 인라인 광고와 기본 광고 include도 게시글에만 허용한다.
- 전체 태그 위젯 Label1은 비활성화한다. 글의 라벨 데이터는 유지한다. 상단 7개 카테고리는 게시글에서도 보이며, 소개·편집 기준/문의·정정/개인정보 링크는 서버 HTML로 제공한다.
- blogger_theme/about.html을 기존 /p/about.html에 반영한다. AI 보조 작성, 별도 AI 검증, 사전 인간 검토 보증 없음, 오류 정정 방식과 7개 주제 안내를 설명한다.

## 작성·별도 검증

공유 autopost/editorial.py의 EDITORIAL_RULES를 Claude brief와 기존 Python writer, Codex 작성 정책 및 별도 검증 단계에서 사용한다. 제목의 총정리 접미사·인사말 복제를 강제하지 않는다. 기존 분량·표·FAQ·공식 근거·최신성·중복 검사는 유지한다.

research.json의 editorial 형식:

- standard_version: 1
- reader_question: 글이 답하는 구체적 독자 질문
- limitations: 실측 여부·적용 조건·미확인 사항
- contributions: 서로 다른 소제목에서 두 종류 이상의 비교/계산/선택 기준/출처 종합 해석
- 각 기여의 kind, section(정확한 소제목), excerpt(그 소제목 본문에서 연속 30자 이상), source_ids, added_value
- source_synthesis는 ID만 다른 같은 URL이 아닌 실제 서로 다른 출처 2개 이상

자동 검사는 기여의 종류·본문 발췌·출처 연결만 확인한다. 독창성의 의미나 사실의 진실성을 보증하지 않으며 별도 검증자가 원문과 본문을 대조해야 한다. 가짜 사용 경험, 조건이 다른 벤치마크 우열, 숨은 가정 계산, 반복 요약은 수정 대상이다. 해결할 근거가 없으면 기존 verification_failed/후보 교체 흐름을 따른다. 새 승인 절차는 만들지 않고 기존 출처 첨부 파일에 독자 가치 기록을 포함한다.

새 작성기는 즉시 위 기록을 만든다. 이미 작성 중인 2026-10-20 원고가 중단되지 않도록 누락 기록의 필수 검사는 KST 원고 폴더 날짜 20261021부터 적용한다. 날짜와 관계없이 v1을 선언한 기록은 즉시 검사한다. published/excluded/사용자 보류 원고를 다시 작성하거나 발행하지 않는다.

## 유지보수·복구

- 테마 변경 전 최신 XML을 다시 백업한다. 전체 테마 교체는 최근 가젯 수정과 충돌할 수 있으므로 이 날짜의 백업을 무조건 재업로드하지 않는다.
- 향후 Blogger가 비게시글에서 새 외부 스크립트를 필요로 하면 실제 화면·기능을 확인하고 CSP 허용 목록을 검토한다. *.google.com 등 광범위 허용이나 광고 호스트 허용을 하지 않는다.
- 승인 이후 사이트별 AdSense 페이지 제외 설정이 사용 가능해지면 네이티브 제외 설정도 검토한다. 승인/실제 광고 노출은 현재 반려 상태에서 검증하거나 보장할 수 없다.
- Google 재검토 요청은 이번 변경 범위에 포함하지 않는다. 기존 글 전체의 독창성 검토·재작성 완료를 의미하지 않는다.
